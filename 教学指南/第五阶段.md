### 2.2 任务 2：实现 OutboxMessageUtil（30 分钟）

**问题引入**：

Canal 推送到 Kafka 的消息格式是固定的 JSON 结构，我们需要一个工具类来解析它，提取 outbox 表的行数据。

**Canal 消息格式**：

```json
{
  "table": "outbox",
  "type": "INSERT",
  "data": [
    {
      "payload": "{\"type\":\"FollowCreated\",\"toUserId\":123,\"fromUserId\":456,\"id\":789}"
    }
  ]
}
```

**参考项目实现**（`源代码/zhiguang_be/src/main/java/com/tongji/common/util/OutboxMessageUtil.java`）：

```java
package com.tongji.common.util;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public final class OutboxMessageUtil {
    private OutboxMessageUtil() {}

    public static List<JsonNode> extractRows(ObjectMapper objectMapper, String message) {
        try {
            JsonNode root = objectMapper.readTree(message);
            JsonNode table = root.get("table");
            if (table == null || !"outbox".equals(table.asText())) {
                return Collections.emptyList();
            }
            JsonNode type = root.get("type");
            if (type == null || (!"INSERT".equals(type.asText()) && !"UPDATE".equals(type.asText()))) {
                return Collections.emptyList();
            }
            JsonNode data = root.get("data");
            if (data == null || !data.isArray()) {
                return Collections.emptyList();
            }
            List<JsonNode> rows = new ArrayList<>();
            data.forEach(rows::add);
            return rows;
        } catch (Exception e) {
            return Collections.emptyList();
        }
    }
}
```

**任务**：

在主项目中创建 `src/main/java/zhiguang/nauy/common/util/OutboxMessageUtil.java`，内容如下：

```java
package zhiguang.nauy.common.util;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

/**
 * Outbox 消息解析工具。
 *
 * <p>用于消费 Canal 推送的 binlog JSON 消息，从中提取 outbox 表的行数据（INSERT/UPDATE）。</p>
 */
public final class OutboxMessageUtil {

    private OutboxMessageUtil() {}

    /**
     * 从 Canal 消息中提取 outbox 表的变更行。
     *
     * @param objectMapper Jackson 解析器
     * @param message Canal JSON 消息
     * @return outbox 行数组；不匹配或解析失败返回空列表
     */
    public static List<JsonNode> extractRows(ObjectMapper objectMapper, String message) {
        try {
            JsonNode root = objectMapper.readTree(message);

            JsonNode table = root.get("table");
            if (table == null || !"outbox".equals(table.asText())) {
                return Collections.emptyList();
            }

            JsonNode type = root.get("type");
            if (type == null || (!"INSERT".equals(type.asText()) && !"UPDATE".equals(type.asText()))) {
                return Collections.emptyList();
            }

            JsonNode data = root.get("data");
            if (data == null || !data.isArray()) {
                return Collections.emptyList();
            }
            List<JsonNode> rows = new ArrayList<>();
            data.forEach(rows::add);
            return rows;
        } catch (Exception e) {
            return Collections.emptyList();
        }
    }
}
```

**逐行讲解**：

1. **`final class` + 私有构造器**：工具类标准写法，禁止实例化
2. **`objectMapper.readTree(message)`**：将 JSON 字符串解析为树形结构（不反序列化为具体类）
3. **三重过滤**：
   - `table == "outbox"`：只处理 outbox 表的变更
   - `type == "INSERT" || "UPDATE"`：只关心新增和更新（Canal 也会推送 DELETE，但我们不需要）
   - `data.isArray()`：确保 data 字段是数组格式
4. **异常处理**：解析失败返回空列表，不抛异常（容错设计）

### 2.4 任务 4：实现 CanalKafkaBridge（3 小时）

**问题引入**：

这是本阶段最核心的组件。Canal 订阅 MySQL binlog，捕获 outbox 表的 INSERT/UPDATE 事件，然后转发到 Kafka。这个桥接器是连接数据库和消息队列的桥梁。

**原理讲解**：

```
Canal Server (独立进程)
    ↓ 订阅 MySQL binlog
    ↓ 捕获 outbox 表变更
    ↓ 推送到 Canal Client
        ↓ CanalKafkaBridge (我们的代码)
            ↓ 解析 ROWDATA
            ↓ 提取 payload 字段
            ↓ 发送到 Kafka topic "canal-outbox"
```

**参考项目实现**（`源代码/zhiguang_be/src/main/java/com/tongji/relation/outbox/CanalKafkaBridge.java`，195 行）

**任务**：

创建 `src/main/java/zhiguang/nauy/relation/outbox/CanalKafkaBridge.java`：

```java
package zhiguang.nauy.relation.outbox;

import com.alibaba.otter.canal.client.CanalConnector;
import com.alibaba.otter.canal.client.CanalConnectors;
import com.alibaba.otter.canal.protocol.CanalEntry;
import com.alibaba.otter.canal.protocol.Message;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ArrayNode;
import com.fasterxml.jackson.databind.node.ObjectNode;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.SmartLifecycle;
import org.springframework.kafka.core.KafkaTemplate;
import org.springframework.core.task.TaskExecutor;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.stereotype.Service;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.net.InetSocketAddress;

/**
 * Canal→Kafka 桥接器。
 *
 * <p>职责：订阅 outbox 表的行级变更（ROWDATA），仅转发 INSERT/UPDATE 的 payload 字段到 Kafka 主题；
 * 批次确认位点确保至少一次语义。</p>
 *
 * <p>可靠性：解析失败或非关心类型不提交位点；停止时断开 Canal 连接并清理资源。</p>
 */
@Service
public class CanalKafkaBridge implements SmartLifecycle {

    private static final Logger log = LoggerFactory.getLogger(CanalKafkaBridge.class);

    private final KafkaTemplate<String, String> kafka;
    private final ObjectMapper objectMapper;
    private final boolean enabled;
    private final String host;
    private final int port;
    private final String destination;
    private final String username;
    private final String password;
    private final String filter;
    private final int batchSize;
    private final long intervalMs;
    private volatile boolean running;
    private final TaskExecutor taskExecutor;
    private CanalConnector connector;

    public CanalKafkaBridge(
            KafkaTemplate<String, String> kafka,
            ObjectMapper objectMapper,
            @Qualifier("threadPoolTaskExecutor") TaskExecutor taskExecutor,
            @Value("${canal.enabled}") boolean enabled,
            @Value("${canal.host}") String host,
            @Value("${canal.port}") int port,
            @Value("${canal.destination}") String destination,
            @Value("${canal.username:}") String username,
            @Value("${canal.password:}") String password,
            @Value("${canal.filter}") String filter,
            @Value("${canal.batchSize:1000}") int batchSize,
            @Value("${canal.intervalMs:1000}") long intervalMs) {
        this.kafka = kafka;
        this.objectMapper = objectMapper;
        this.taskExecutor = taskExecutor;
        this.enabled = enabled;
        this.host = host;
        this.port = port;
        this.destination = destination;
        this.username = username;
        this.password = password;
        this.filter = filter;
        this.batchSize = batchSize;
        this.intervalMs = intervalMs;
    }

    @Override
    public void start() {
        if (running) {
            log.info("Canal bridge start skipped: running={} enabled={}", running, enabled);
            return;
        }
        running = true;
        taskExecutor.execute(() -> {
            CanalConnector conn = null;
            try {
                conn = CanalConnectors.newSingleConnector(
                        new InetSocketAddress(host, port),
                        destination,
                        username,
                        password
                );
                conn.connect();
                conn.subscribe(filter);
                conn.rollback();
                connector = conn;
                log.info("Canal connected: host={} port={} dest={} filter={}",
                        host, port, destination, filter);

                while (running) {
                    Message message = conn.getWithoutAck(batchSize);
                    long batchId = message.getId();

                    if (batchId == -1 || message.getEntries() == null || message.getEntries().isEmpty()) {
                        try {
                            Thread.sleep(intervalMs);
                        } catch (InterruptedException ignored) {
                            Thread.currentThread().interrupt();
                        }
                        continue;
                    }

                    for (CanalEntry.Entry entry : message.getEntries()) {
                        if (entry.getEntryType() != CanalEntry.EntryType.ROWDATA) {
                            continue;
                        }

                        CanalEntry.RowChange rowChange;
                        try {
                            rowChange = CanalEntry.RowChange.parseFrom(entry.getStoreValue());
                        } catch (Exception e) {
                            log.warn("Failed to parse RowChange: {}", e.getMessage());
                            continue;
                        }

                        CanalEntry.EventType eventType = rowChange.getEventType();
                        if (eventType != CanalEntry.EventType.INSERT
                                && eventType != CanalEntry.EventType.UPDATE) {
                            continue;
                        }

                        ArrayNode dataArray = objectMapper.createArrayNode();
                        for (CanalEntry.RowData rowData : rowChange.getRowDatasList()) {
                            ObjectNode rowNode = objectMapper.createObjectNode();
                            for (CanalEntry.Column col : rowData.getAfterColumnsList()) {
                                if ("payload".equalsIgnoreCase(col.getName())) {
                                    rowNode.put("payload", col.getValue());
                                }
                            }
                            dataArray.add(rowNode);
                        }

                        ObjectNode msgNode = objectMapper.createObjectNode();
                        msgNode.put("table", entry.getHeader().getTableName());
                        msgNode.put("type", eventType == CanalEntry.EventType.INSERT
                                ? "INSERT" : "UPDATE");
                        msgNode.set("data", dataArray);

                        try {
                            String json = objectMapper.writeValueAsString(msgNode);
                            kafka.send(OutboxTopics.CANAL_OUTBOX, json);
                        } catch (Exception e) {
                            log.warn("Failed to send to Kafka: {}", e.getMessage());
                        }
                    }

                    conn.ack(batchId);
                }
            } catch (Exception e) {
                log.error("Canal bridge error", e);
            } finally {
                if (conn != null) {
                    try {
                        conn.disconnect();
                        log.info("Canal disconnected: dest={}", destination);
                    } catch (Exception ex) {
                        log.warn("Canal disconnect failed: {}", ex.getMessage());
                    }
                }
            }
        });
    }

    @Override
    public void stop() {
        running = false;
    }

    @Override
    public boolean isRunning() {
        return running;
    }
}
```

**逐段讲解**：

**1. 为什么实现 `SmartLifecycle`？**

```java
public class CanalKafkaBridge implements SmartLifecycle {
```

`SmartLifecycle` 是 Spring 提供的生命周期接口，比 `@PostConstruct` 更灵活：
- `start()`：Spring 容器就绪后自动调用
- `stop()`：应用关闭时自动调用
- `isRunning()`：查询运行状态

Canal 桥接器需要在应用启动后开始监听，关闭时优雅断开，所以用 `SmartLifecycle` 最合适。

**2. 为什么用 `@Qualifier("threadPoolTaskExecutor")`？**

```java
@Qualifier("threadPoolTaskExecutor") TaskExecutor taskExecutor
```

Canal 的轮询循环是阻塞式的，如果在主线程运行会阻塞 Spring 启动。所以需要一个独立线程池来运行轮询循环。

参考项目中使用 `"taskExecutor"` 作为 Bean 名称，但我们的项目中 `ThreadPoolConfig.java` 定义的 Bean 名称是 `"threadPoolTaskExecutor"`。

**3. 轮询循环核心逻辑**

```java
while (running) {
    Message message = conn.getWithoutAck(batchSize);
    long batchId = message.getId();
    // ...
    conn.ack(batchId);
}
```

这是 Canal Client 的标准使用模式：
1. `getWithoutAck(batchSize)`：拉取一批消息，但不自动确认位点
2. 处理消息（解析 + 发送到 Kafka）
3. `ack(batchId)`：确认这批消息已处理，推进位点

**为什么不用自动确认？** 如果处理过程中失败了，未 ack 的消息会被 Canal 重新投递，保证至少一次语义。

**4. 消息解析流程**

```java
CanalEntry.RowChange rowChange = CanalEntry.RowChange.parseFrom(entry.getStoreValue());
// ...
for (CanalEntry.RowData rowData : rowChange.getRowDatasList()) {
    ObjectNode rowNode = objectMapper.createObjectNode();
    for (CanalEntry.Column col : rowData.getAfterColumnsList()) {
        if ("payload".equalsIgnoreCase(col.getName())) {
            rowNode.put("payload", col.getValue());
        }
    }
    dataArray.add(rowNode);
}
```

- `ROWDATA` 类型的 entry 才包含实际的行数据
- `RowChange` 包含事件类型（INSERT/UPDATE/DELETE）和行数据列表
- `getAfterColumnsList()` 获取变更后的列数据（如果是 INSERT/UPDATE）
- 我们只关心 `payload` 列，其他列忽略

**5. 发送到 Kafka**

```java
ObjectNode msgNode = objectMapper.createObjectNode();
msgNode.put("table", entry.getHeader().getTableName());
msgNode.put("type", eventType == CanalEntry.EventType.INSERT ? "INSERT" : "UPDATE");
msgNode.set("data", dataArray);

String json = objectMapper.writeValueAsString(msgNode);
kafka.send(OutboxTopics.CANAL_OUTBOX, json);
```

构造的消息格式：
```json
{
  "table": "outbox",
  "type": "INSERT",
  "data": [{"payload": "..."}]
}
```

下游消费者（CanalOutboxConsumer）会用 `OutboxMessageUtil` 解析这个格式。

**踩坑点**：

1. **Canal filter 表达式格式**：`application.yaml` 中配置的是 `zhiguang\.outbox`，反斜杠转义点号。Canal 的 filter 语法要求这样写。

3. **Bean 名称不匹配**：参考项目用 `@Qualifier("taskExecutor")`，我们的项目 Bean 名称是 `"threadPoolTaskExecutor"`，必须改。

**问题引入**：

CanalKafkaBridge 已经把 outbox 表的变更发送到 Kafka topic `canal-outbox`，现在需要一个消费者来监听这个 topic，提取 payload 并交给 RelationEventProcessor 处理。

**任务**：

```java
package zhiguang.nauy.relation.outbox;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import zhiguang.nauy.relation.event.RelationEvent;
import zhiguang.nauy.relation.processor.RelationEventProcessor;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.support.Acknowledgment;
import org.springframework.stereotype.Service;
import zhiguang.nauy.common.util.OutboxMessageUtil;

import java.util.List;

/**
 * Canal Outbox 消费者。
 *
 * <p>职责：消费 Canal 桥接写入的 outbox 主题消息，提取 payload 并反序列化为 RelationEvent，
 * 交由处理器落库与更新缓存/计数；使用手动位点确保处理成功语义。</p>
 */
@Service
public class CanalOutboxConsumer {

    private final ObjectMapper objectMapper;
    private final RelationEventProcessor processor;

    public CanalOutboxConsumer(ObjectMapper objectMapper, RelationEventProcessor processor) {
        this.objectMapper = objectMapper;
        this.processor = processor;
    }

    /**
     * 消费 Canal outbox 消息并转为关系事件处理。
     *
     * @param message Kafka 消息内容
     * @param ack 位点确认对象
     */
    @KafkaListener(topics = OutboxTopics.CANAL_OUTBOX, groupId = "relation-outbox-consumer")
    public void onMessage(String message, Acknowledgment ack) {
        try {
            List<JsonNode> rows = OutboxMessageUtil.extractRows(objectMapper, message);
            if (rows.isEmpty()) {
                ack.acknowledge();
                return;
            }
            for (JsonNode row : rows) {
                JsonNode payloadNode = row.get("payload");
                if (payloadNode == null) {
                    continue;
                }
                RelationEvent evt = objectMapper.readValue(
                        payloadNode.asText(), RelationEvent.class);
                processor.process(evt);
            }
            ack.acknowledge();
        } catch (Exception e) {
            // 消费失败不 ack，等待 Kafka 重试
        }
    }
}
```

**逐行讲解**：

**1. `@KafkaListener` 注解**

```java
@KafkaListener(topics = OutboxTopics.CANAL_OUTBOX, groupId = "relation-outbox-consumer")
```

- `topics`：监听 `canal-outbox` topic
- `groupId`：消费者组名。不同的消费者组独立消费，互不影响
  - `relation-outbox-consumer`：处理关系事件
  - `search-index-consumer`（Day 5 实现）：处理搜索索引更新

**2. 手动位点提交**

```java
public void onMessage(String message, Acknowledgment ack) {
    try {
        // ... 处理逻辑 ...
        ack.acknowledge();  // 处理成功才确认
    } catch (Exception e) {
        // 消费失败不 ack，等待 Kafka 重试
    }
}
```

`Acknowledgment` 是手动位点提交的关键：
- 处理成功：调用 `ack.acknowledge()` 确认
- 处理失败：不调用 ack，Kafka 会在消费者重启后重新投递

这保证了"至少一次"语义：消息不会丢失，但可能被重复消费（所以 RelationEventProcessor 需要做幂等去重）。

**3. 消息解析流程**

```
Kafka message (JSON string)
  -> OutboxMessageUtil.extractRows()  // 提取 outbox 行
    -> row.get("payload")             // 获取 payload 字段
      -> objectMapper.readValue()     // 反序列化为 RelationEvent
        -> processor.process(evt)     // 交给处理器
```

### 3.3 任务 3：实现 RelationEventProcessor（1.5 小时）

**问题引入**：

CanalOutboxConsumer 已经把消息解析为 `RelationEvent`，现在需要一个处理器来执行真正的业务逻辑：写入 follower 表、更新 Redis 缓存、同步用户计数器。

**参考项目实现**（`源代码/zhiguang_be/src/main/java/com/tongji/relation/processor/RelationEventProcessor.java`，66 行）

**任务**：

创建 `src/main/java/zhiguang/nauy/relation/processor/RelationEventProcessor.java`：

```java
package zhiguang.nauy.relation.processor;

import zhiguang.nauy.relation.event.RelationEvent;
import zhiguang.nauy.relation.mapper.RelationMapper;
import org.springframework.data.redis.core.StringRedisTemplate;
import zhiguang.nauy.counter.service.UserCounterService;
import org.springframework.stereotype.Service;

import java.time.Duration;

/**
 * 关系事件处理器。
 *
 * <p>职责：对 FollowCreated/FollowCanceled 事件进行去重、防抖与幂等处理，
 * 落库更新粉丝表，维护关注/粉丝 ZSet 缓存与 TTL，并原子更新用户维度计数（SDS）。</p>
 */
@Service
public class RelationEventProcessor {

    private final RelationMapper mapper;
    private final StringRedisTemplate redis;
    private final UserCounterService userCounterService;

    public RelationEventProcessor(
            RelationMapper mapper,
            StringRedisTemplate redis,
            UserCounterService userCounterService) {
        this.mapper = mapper;
        this.redis = redis;
        this.userCounterService = userCounterService;
    }

    /**
     * 处理关系事件：入库、更新缓存、刷新计数，并进行幂等去重。
     *
     * @param evt 关系事件
     */
    public void process(RelationEvent evt) {
        // 1. 幂等去重：Redis SETNX，10 分钟过期
        String dk = "dedup:rel:" + evt.getType() + ":"
                + evt.getFromUserId() + ":" + evt.getToUserId() + ":"
                + (evt.getId() == null ? "0" : String.valueOf(evt.getId()));
        Boolean first = redis.opsForValue().setIfAbsent(dk, "1", Duration.ofMinutes(10));

        if (first == null || !first) {
            return;  // 非首次，直接返回
        }

        // 2. 根据事件类型执行业务逻辑
        if ("FollowCreated".equals(evt.getType())) {
            // 写入 follower 表
            mapper.insertFollower(evt.getId(), evt.getToUserId(), evt.getFromUserId(), 1);

            long now = System.currentTimeMillis();
            // 更新 Redis ZSet 缓存
            redis.opsForZSet().add("uf:flws:" + evt.getFromUserId(),
                    String.valueOf(evt.getToUserId()), now);
            redis.opsForZSet().add("uf:fans:" + evt.getToUserId(),
                    String.valueOf(evt.getFromUserId()), now);
            redis.expire("uf:flws:" + evt.getFromUserId(), Duration.ofHours(2));
            redis.expire("uf:fans:" + evt.getToUserId(), Duration.ofHours(2));

            // 同步用户计数器
            userCounterService.incrementFollowings(evt.getFromUserId(), 1);
            userCounterService.incrementFollowers(evt.getToUserId(), 1);

        } else if ("FollowCanceled".equals(evt.getType())) {
            // 取消粉丝关系
            mapper.cancelFollower(evt.getToUserId(), evt.getFromUserId());

            // 更新 Redis ZSet 缓存
            redis.opsForZSet().remove("uf:flws:" + evt.getFromUserId(),
                    String.valueOf(evt.getToUserId()));
            redis.opsForZSet().remove("uf:fans:" + evt.getToUserId(),
                    String.valueOf(evt.getFromUserId()));
            redis.expire("uf:flws:" + evt.getFromUserId(), Duration.ofHours(2));
            redis.expire("uf:fans:" + evt.getToUserId(), Duration.ofHours(2));

            // 同步用户计数器
            userCounterService.incrementFollowings(evt.getFromUserId(), -1);
            userCounterService.incrementFollowers(evt.getToUserId(), -1);
        }
    }
}
```

**逐段讲解**：

**1. 幂等去重机制**

```java
String dk = "dedup:rel:" + evt.getType() + ":"
        + evt.getFromUserId() + ":" + evt.getToUserId() + ":"
        + (evt.getId() == null ? "0" : String.valueOf(evt.getId()));
Boolean first = redis.opsForValue().setIfAbsent(dk, "1", Duration.ofMinutes(10));
```

为什么需要去重？因为 Canal + Kafka 保证的是"至少一次"语义，同一条消息可能被投递多次。

去重键设计：`dedup:rel:FollowCreated:456:123:789`
- `FollowCreated`：事件类型
- `456`：fromUserId
- `123`：toUserId
- `789`：关系ID

`setIfAbsent`（Redis SETNX）：只有键不存在时才设置，返回 `true` 表示首次写入。10 分钟后自动过期，释放去重键。

**2. FollowCreated 处理**

```java
mapper.insertFollower(evt.getId(), evt.getToUserId(), evt.getFromUserId(), 1);
```

向 `follower` 表写入粉丝关系。注意参数顺序：`toUserId` 在前，`fromUserId` 在后（与 `follower` 表的字段顺序一致）。

```java
redis.opsForZSet().add("uf:flws:" + evt.getFromUserId(),
        String.valueOf(evt.getToUserId()), now);
```

更新关注列表缓存：`uf:flws:{userId}` ZSet，分数为时间戳。这样查询"我的关注"时可以直接从 Redis 读取，不用查数据库。

```java
userCounterService.incrementFollowings(evt.getFromUserId(), 1);
userCounterService.incrementFollowers(evt.getToUserId(), 1);
```

同步用户维度的计数器（SDS 结构），增加关注数和粉丝数。

**3. FollowCanceled 处理**

与 FollowCreated 相反：删除 follower 记录、从 ZSet 移除、计数器减 1。

**踩坑点**：

1. **RelationEvent 的 getter 方法**：`RelationEvent` 使用了 `@Data`（Lombok），所以 getter 方法是 `getType()`、`getFromUserId()` 等，不是 `type()`、`fromUserId()`。参考项目使用的是 Java 16+ 的 record，getter 是 `type()`、`fromUserId()`，需要注意区别。

2. **insertFollower 的参数顺序**：`follower` 表的字段顺序是 `to_user_id` 在前，`from_user_id` 在后，与 `following` 表相反。

### 5.1 RAG 原理讲解

**RAG（Retrieval-Augmented Generation）** = 检索增强生成

```
用户提问
  ↓
1. 语义检索：从知识库中找到最相关的文档片段
  ↓
2. 上下文拼接：将检索结果 + 用户问题 组合成提示词
  ↓
3. LLM 生成：基于上下文生成答案
```

**为什么需要 RAG？**

LLM 的知识截止到训练数据的时间点，无法回答关于最新内容的问题。RAG 通过"先检索，再生成"的方式，让 LLM 能够基于最新的知识库内容回答问题。

**Spring AI 的 VectorStore 抽象**：

```
文档 → 分块 → 嵌入向量（Embedding）→ 存储到 ES VectorStore
                                           ↓
用户查询 → 嵌入向量 → 相似度搜索 → 检索结果 → LLM 生成
```

### 5.2 任务 1：实现 RagIndexService（2.5 小时）

**任务**：

创建 `src/main/java/zhiguang/nauy/llm/rag/RagIndexService.java`：

```java
package zhiguang.nauy.llm.rag;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.document.Document;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;
import zhiguang.nauy.knowpost.mapper.KnowPostMapper;
import zhiguang.nauy.knowpost.domain.KnowPost;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.*;

/**
 * RAG 索引服务。
 *
 * <p>负责将知文内容分块、向量化并存储到 ES VectorStore，
 * 支持指纹去重和增量更新。</p>
 */
@Service
public class RagIndexService {

    private static final Logger log = LoggerFactory.getLogger(RagIndexService.class);

    private static final int CHUNK_SIZE = 800;
    private static final int CHUNK_OVERLAP = 100;

    private final VectorStore vectorStore;
    private final KnowPostMapper knowPostMapper;
    private final RestTemplate restTemplate;
    private final EmbeddingModel embeddingModel;

    public RagIndexService(
            VectorStore vectorStore,
            KnowPostMapper knowPostMapper,
            RestTemplate restTemplate,
            EmbeddingModel embeddingModel) {
        this.vectorStore = vectorStore;
        this.knowPostMapper = knowPostMapper;
        this.restTemplate = restTemplate;
        this.embeddingModel = embeddingModel;
    }

    /**
     * 确保帖子已索引，未变更则跳过。
     */
    public int ensureIndexed(Long postId) {
        return reindexSinglePost(postId);
    }

    /**
     * 重建单个帖子的 RAG 索引。
     *
     * @return 索引的 chunk 数量
     */
    private int reindexSinglePost(Long postId) {
        // 1. 查询帖子信息
        KnowPost post = knowPostMapper.selectById(postId);
        if (post == null || !"published".equals(post.getStatus())) {
            log.warn("Post not found or not published: {}", postId);
            return 0;
        }

        // 2. 指纹检查：如果内容未变更，跳过
        String contentUrl = post.getContentUrl();
        if (contentUrl == null || contentUrl.isBlank()) {
            log.warn("Post has no content URL: {}", postId);
            return 0;
        }

        String content;
        try {
            content = restTemplate.getForObject(contentUrl, String.class);
        } catch (Exception e) {
            log.warn("Failed to fetch content from URL: {}", contentUrl);
            return 0;
        }

        if (content == null || content.isBlank()) {
            return 0;
        }

        String contentSha256 = sha256(content);

        // 检查是否已索引且内容未变更
        List<Document> existing = vectorStore.similaritySearch(
                SearchRequest.query("match")
                        .withTopK(1)
                        .withFilterExpression("metadata.postId == '" + postId + "'"));
        if (!existing.isEmpty()) {
            String existingHash = (String) existing.get(0).getMetadata().get("contentSha256");
            if (contentSha256.equals(existingHash)) {
                log.debug("Post {} content unchanged, skipping reindex", postId);
                return 0;
            }
        }

        // 3. 删除旧索引
        vectorStore.delete(List.of("metadata.postId == '" + postId + "'"));

        // 4. 分块
        List<String> chunks = chunkMarkdown(content);
        if (chunks.isEmpty()) {
            return 0;
        }

        // 5. 构建 Document 列表
        String title = post.getTitle() != null ? post.getTitle() : "";
        List<Document> documents = new ArrayList<>();
        for (int i = 0; i < chunks.size(); i++) {
            Map<String, Object> metadata = new HashMap<>();
            metadata.put("postId", String.valueOf(postId));
            metadata.put("chunkId", postId + "_chunk_" + i);
            metadata.put("position", i);
            metadata.put("contentSha256", contentSha256);
            metadata.put("contentUrl", contentUrl);
            metadata.put("title", title);

            documents.add(new Document(chunks.get(i), metadata));
        }

        // 6. 写入 VectorStore
        vectorStore.add(documents);
        log.info("Indexed {} chunks for post {}", documents.size(), postId);
        return documents.size();
    }

    /**
     * Markdown 分块：按标题分割 → 滑动窗口。
     */
    List<String> chunkMarkdown(String markdown) {
        List<String> sections = new ArrayList<>();
        String[] lines = markdown.split("\n");
        StringBuilder current = new StringBuilder();

        for (String line : lines) {
            if (line.startsWith("#") && !current.isEmpty()) {
                sections.add(current.toString());
                current = new StringBuilder();
            }
            current.append(line).append("\n");
        }
        if (!current.isEmpty()) {
            sections.add(current.toString());
        }

        // 对每个 section 应用滑动窗口
        List<String> chunks = new ArrayList<>();
        for (String section : sections) {
            if (section.length() <= CHUNK_SIZE) {
                chunks.add(section.trim());
            } else {
                int start = 0;
                while (start < section.length()) {
                    int end = Math.min(start + CHUNK_SIZE, section.length());
                    chunks.add(section.substring(start, end).trim());
                    start += CHUNK_SIZE - CHUNK_OVERLAP;
                }
            }
        }
        return chunks;
    }

    /**
     * SHA-256 哈希。
     */
    private String sha256(String content) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hash = digest.digest(content.getBytes(StandardCharsets.UTF_8));
            StringBuilder hex = new StringBuilder();
            for (byte b : hash) {
                hex.append(String.format("%02x", b));
            }
            return hex.toString();
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException(e);
        }
    }
}
```

**关键设计点**：

1. **指纹去重**：`contentSha256` 存储在 Document 的 metadata 中，下次索引时对比，内容未变更则跳过
2. **先删后建**：`vectorStore.delete()` + `vectorStore.add()`，保证幂等性
3. **分块策略**：先按 Markdown 标题分割，再用滑动窗口（800 字符，100 字符重叠）切分长段落

```java
package zhiguang.nauy.llm.rag;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.deepseek.DeepSeekChatOptions;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;
import reactor.core.publisher.Flux;

import java.util.List;
import java.util.stream.Collectors;

/**
 * RAG 查询服务。
 *
 * <p>基于 VectorStore 语义检索 + ChatClient 流式生成，
 * 为知文提供知识问答能力。</p>
 */
@Service
public class RagQueryService {

    private static final Logger log = LoggerFactory.getLogger(RagQueryService.class);

    private final VectorStore vectorStore;
    private final ChatClient chatClient;
    private final RagIndexService indexService;

    public RagQueryService(
            VectorStore vectorStore,
            ChatClient chatClient,
            RagIndexService indexService) {
        this.vectorStore = vectorStore;
        this.chatClient = chatClient;
        this.indexService = indexService;
    }

    /**
     * 流式回答知文相关问题。
     *
     * @param postId  帖子ID
     * @param question 用户问题
     * @param topK    检索数量
     * @param maxTokens 最大生成 token 数
     * @return 流式文本响应
     */
    public Flux<String> streamAnswerFlux(Long postId, String question, int topK, int maxTokens) {
        // 1. 确保索引是最新的
        indexService.ensureIndexed(postId);

        // 2. 语义检索
        int fetchK = Math.max(topK * 3, 20);
        List<Document> results = vectorStore.similaritySearch(
                SearchRequest.query(question)
                        .withTopK(fetchK)
                        .withFilterExpression("metadata.postId == '" + postId + "'"));

        // 3. 后过滤：只保留当前帖子的 chunks
        List<String> contexts = results.stream()
                .filter(doc -> postId.toString().equals(doc.getMetadata().get("postId")))
                .limit(topK)
                .map(Document::getText)
                .collect(Collectors.toList());

        if (contexts.isEmpty()) {
            return Flux.just("抱歉，未能找到与该问题相关的内容。");
        }

        // 4. 构建提示词
        String contextStr = String.join("\n---\n", contexts);
        String systemPrompt = "你是中文知识助手。根据提供的上下文回答用户问题。"
                + "如果上下文中没有相关信息，请说明无法回答。"
                + "回答要准确、简洁，引用上下文中的具体内容。";
        String userPrompt = "上下文：\n" + contextStr + "\n\n问题：" + question;

        // 5. 流式生成
        return chatClient.prompt()
                .system(systemPrompt)
                .user(userPrompt)
                .options(DeepSeekChatOptions.builder()
                        .model("deepseek-chat")
                        .temperature(0.7)
                        .maxTokens(maxTokens)
                        .build())
                .stream()
                .content();
    }
}
```

**关键设计点**：

1. **fetchK vs topK**：`fetchK = topK * 3`，先宽范围召回，再后过滤，提高召回率
2. **后过滤**：`vectorStore.similaritySearch` 返回的是全局最相似的文档，需要过滤只保留当前帖子的 chunks
3. **流式返回**：`.stream().content()` 返回 `Flux<String>`，配合 SSE 实现打字机效果

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.mapping.Property;
import co.elastic.clients.elasticsearch._types.mapping.TextProperty;
import co.elastic.clients.elasticsearch._types.mapping.KeywordProperty;
import co.elastic.clients.elasticsearch._types.mapping.CompletionProperty;
import co.elastic.clients.elasticsearch.indices.CreateIndexRequest;
import co.elastic.clients.elasticsearch.indices.ExistsRequest;
import jakarta.annotation.PostConstruct;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

import java.io.IOException;

/**
 * ES 搜索索引初始化器。
 *
 * <p>应用启动时自动创建 zhiguang_content_index 索引，
 * 配置 IK 分词器和 completion suggester。</p>
 */
@Component
public class SearchIndexInitializer {

    private static final Logger log = LoggerFactory.getLogger(SearchIndexInitializer.class);
    private static final String INDEX_NAME = "zhiguang_content_index";

    private final ElasticsearchClient esClient;

    public SearchIndexInitializer(ElasticsearchClient esClient) {
        this.esClient = esClient;
    }

    @PostConstruct
    public void init() {
        try {
            boolean exists = esClient.indices().exists(
                    ExistsRequest.of(e -> e.index(INDEX_NAME))).value();
            if (!exists) {
                createIndex();
                log.info("Created search index: {}", INDEX_NAME);
            }
        } catch (IOException e) {
            log.warn("Failed to check/create search index: {}", e.getMessage());
        }
    }

    private void createIndex() throws IOException {
        esClient.indices().create(CreateIndexRequest.of(c -> c
                .index(INDEX_NAME)
                .mappings(m -> m
                        .properties("title", Property.of(p -> p
                                .text(TextProperty.of(t -> t
                                        .analyzer("ik_max_word")
                                        .searchAnalyzer("ik_smart")
                                        .copyTo("title_suggest")))))
                        .properties("body", Property.of(p -> p
                                .text(TextProperty.of(t -> t
                                        .analyzer("ik_max_word")
                                        .searchAnalyzer("ik_smart")))))
                        .properties("title_suggest", Property.of(p -> p
                                .completion(CompletionProperty.of(cp -> cp))))
                        .properties("postId", Property.of(p -> p
                                .keyword(KeywordProperty.of(k -> k)))))
                .settings(s -> s
                        .numberOfShards("1")
                        .numberOfReplicas("0"))
        ));
    }
}
```

**关键点**：

1. **`@PostConstruct`**：应用启动后自动执行
2. **IK 分词器**：`ik_max_word`（最细粒度分词）用于索引，`ik_smart`（智能分词）用于搜索
3. **completion suggester**：ES 原生的联想建议功能，输入即提示

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.query_dsl.Query;
import co.elastic.clients.elasticsearch.core.*;
import co.elastic.clients.elasticsearch.core.bulk.BulkResponseItem;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;
import zhiguang.nauy.counter.service.CounterService;
import zhiguang.nauy.knowpost.domain.KnowPost;
import zhiguang.nauy.knowpost.mapper.KnowPostMapper;

import java.io.IOException;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * ES 索引写入服务。
 *
 * <p>负责知文的索引写入、更新和软删除。
 * 启动时自动回填已有帖子。</p>
 */
@Service
public class SearchIndexService {

    private static final Logger log = LoggerFactory.getLogger(SearchIndexService.class);
    private static final String INDEX_NAME = "zhiguang_content_index";

    private final ElasticsearchClient esClient;
    private final KnowPostMapper knowPostMapper;
    private final RestTemplate restTemplate;
    private final CounterService counterService;

    public SearchIndexService(
            ElasticsearchClient esClient,
            KnowPostMapper knowPostMapper,
            RestTemplate restTemplate,
            CounterService counterService) {
        this.esClient = esClient;
        this.knowPostMapper = knowPostMapper;
        this.restTemplate = restTemplate;
        this.counterService = counterService;
    }

    @PostConstruct
    public void ensureBackfill() {
        try {
            long count = esClient.count(c -> c.index(INDEX_NAME)).count();
            if (count == 0) {
                backfillAll();
            }
        } catch (IOException e) {
            log.warn("Failed to check ES count: {}", e.getMessage());
        }
    }

    private void backfillAll() {
        log.info("Starting full backfill...");
        List<KnowPost> posts = knowPostMapper.selectList(null);
        int indexed = 0;
        for (KnowPost post : posts) {
            if ("published".equals(post.getStatus())) {
                try {
                    upsertKnowPost(post.getId());
                    indexed++;
                } catch (Exception e) {
                    log.warn("Failed to index post {}: {}", post.getId(), e.getMessage());
                }
            }
        }
        log.info("Backfill completed: {}/{} posts indexed", indexed, posts.size());
    }

    /**
     * 索引或更新单个帖子。
     */
    public void upsertKnowPost(Long postId) throws IOException {
        KnowPost post = knowPostMapper.selectById(postId);
        if (post == null || !"published".equals(post.getStatus())) {
            return;
        }

        String title = post.getTitle() != null ? post.getTitle() : "";
        String body = "";
        if (post.getContentUrl() != null && !post.getContentUrl().isBlank()) {
            try {
                body = restTemplate.getForObject(post.getContentUrl(), String.class);
            } catch (Exception e) {
                log.warn("Failed to fetch content for post {}: {}", postId, e.getMessage());
            }
        }

        Map<String, Object> doc = new HashMap<>();
        doc.put("postId", String.valueOf(postId));
        doc.put("title", title);
        doc.put("body", body != null ? body : "");
        doc.put("creatorId", String.valueOf(post.getCreatorId()));

        // 获取计数数据
        try {
            Map<String, Long> counts = counterService.getCounts("knowpost", postId);
            doc.put("likeCount", counts.getOrDefault("like", 0L));
            doc.put("favCount", counts.getOrDefault("fav", 0L));
        } catch (Exception e) {
            doc.put("likeCount", 0L);
            doc.put("favCount", 0L);
        }

        esClient.index(i -> i
                .index(INDEX_NAME)
                .id(String.valueOf(postId))
                .document(doc)
                .refresh(r -> r.waitFor(true)));
    }

    /**
     * 软删除帖子索引。
     */
    public void softDeleteKnowPost(Long postId) throws IOException {
        esClient.delete(d -> d
                .index(INDEX_NAME)
                .id(String.valueOf(postId)));
    }
}
```

```java
package zhiguang.nauy.search.outbox;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.support.Acknowledgment;
import org.springframework.stereotype.Service;
import zhiguang.nauy.common.util.OutboxMessageUtil;
import zhiguang.nauy.search.index.SearchIndexService;

import java.util.List;

/**
 * Canal Outbox 消费者（搜索索引）。
 *
 * <p>监听 canal-outbox topic，处理知文相关的事件，
 * 触发 ES 索引的增量更新。</p>
 */
@Service
public class CanalOutboxConsumerSearch {

    private final ObjectMapper objectMapper;
    private final SearchIndexService searchIndexService;

    public CanalOutboxConsumerSearch(
            ObjectMapper objectMapper,
            SearchIndexService searchIndexService) {
        this.objectMapper = objectMapper;
        this.searchIndexService = searchIndexService;
    }

    @KafkaListener(topics = "canal-outbox", groupId = "search-index-consumer")
    public void onMessage(String message, Acknowledgment ack) {
        try {
            List<JsonNode> rows = OutboxMessageUtil.extractRows(objectMapper, message);
            if (rows.isEmpty()) {
                ack.acknowledge();
                return;
            }

            for (JsonNode row : rows) {
                JsonNode payloadNode = row.get("payload");
                if (payloadNode == null) {
                    continue;
                }

                // 解析 payload，判断是否为知文事件
                String payloadStr = payloadNode.asText();
                // 只处理知文相关的事件
                // 实际项目中需要根据 payload 的 aggregateType 判断
                // 这里简化处理：尝试解析并索引
                try {
                    JsonNode payload = objectMapper.readTree(payloadStr);
                    String aggregateType = payload.has("aggregateType")
                            ? payload.get("aggregateType").asText() : "";
                    // 如果是知文事件，触发索引更新
                    if ("knowpost".equals(aggregateType)) {
                        Long postId = payload.has("aggregateId")
                                ? Long.parseLong(payload.get("aggregateId").asText()) : null;
                        if (postId != null) {
                            searchIndexService.upsertKnowPost(postId);
                        }
                    }
                } catch (Exception e) {
                    // 忽略解析失败
                }
            }

            ack.acknowledge();
        } catch (Exception e) {
            // 消费失败不 ack
        }
    }
}
```

```java
package zhiguang.nauy.search.service.impl;

import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.SortOrder;
import co.elastic.clients.elasticsearch.core.SearchResponse;
import co.elastic.clients.elasticsearch.core.search.Hit;
import org.springframework.stereotype.Service;
import zhiguang.nauy.search.service.SearchService;
import zhiguang.nauy.search.service.dto.SearchResult;

import java.io.IOException;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;

@Service
public class SearchServiceImpl implements SearchService {

    private static final String INDEX_NAME = "zhiguang_content_index";

    private final ElasticsearchClient esClient;

    public SearchServiceImpl(ElasticsearchClient esClient) {
        this.esClient = esClient;
    }

    @Override
    public List<SearchResult> search(String query, int page, int size) {
        try {
            int from = (page - 1) * size;
            SearchResponse<Map> response = esClient.search(s -> s
                    .index(INDEX_NAME)
                    .query(q -> q.multiMatch(m -> m
                            .fields("title", "body")
                            .query(query)))
                    .from(from)
                    .size(size)
                    .sort(so -> so
                            .field(f -> f.field("likeCount").order(SortOrder.Desc))),
                    Map.class);

            List<SearchResult> results = new ArrayList<>();
            for (Hit<Map> hit : response.hits().hits()) {
                Map<String, Object> doc = hit.source();
                if (doc == null) continue;
                results.add(new SearchResult(
                        Long.parseLong((String) doc.get("postId")),
                        (String) doc.get("title"),
                        truncate((String) doc.get("body"), 200),
                        doc.get("likeCount") != null ? ((Number) doc.get("likeCount")).longValue() : 0,
                        doc.get("favCount") != null ? ((Number) doc.get("favCount")).longValue() : 0
                ));
            }
            return results;
        } catch (IOException e) {
            return List.of();
        }
    }

    @Override
    public List<String> suggest(String prefix, int size) {
        try {
            SearchResponse<Map> response = esClient.search(s -> s
                    .index(INDEX_NAME)
                    .suggest(su -> su
                            .suggesters("title-suggest", sg -> sg
                                    .completion(c -> c
                                            .field("title_suggest")
                                            .prefix(prefix)
                                            .size(size)))),
                    Map.class);

            List<String> suggestions = new ArrayList<>();
            if (response.suggest() != null) {
                var titleSuggest = response.suggest().get("title-suggest");
                if (titleSuggest != null) {
                    for (var option : titleSuggest) {
                        for (var entry : option.options()) {
                            suggestions.add(entry.text());
                        }
                    }
                }
            }
            return suggestions;
        } catch (IOException e) {
            return List.of();
        }
    }

    private String truncate(String text, int maxLen) {
        if (text == null) return "";
        return text.length() > maxLen ? text.substring(0, maxLen) + "..." : text;
    }
}
```

## 九、常见问题

### Q1: Canal Server 连接失败？

检查：
1. Canal Server 是否启动（Docker 或本地）
2. `application.yaml` 中的 `canal.host` 和 `canal.port` 是否正确
3. MySQL binlog 是否开启（`log_bin=ON`）

### Q2: Kafka 消费者收不到消息？

检查：
1. Kafka 是否启动
2. topic `canal-outbox` 是否存在
3. CanalKafkaBridge 是否正常运行（检查日志）

### Q3: DeepSeek API 调用失败？

检查：
1. `DEEPSEEK_API_KEY` 环境变量是否设置
2. `application.yaml` 中的 `deepseek.base-url` 是否正确
3. 网络是否能访问 `api.deepseek.com`

### Q4: Elasticsearch 搜索无结果？

检查：
1. ES 是否启动（localhost:9200）
2. 索引是否存在（`curl localhost:9200/_cat/indices`）
3. 索引是否有数据（`curl localhost:9200/zhiguang_content_index/_count`）
4. IK 分词器是否安装
