### 1.1 分布式 ID 生成器

**路径**：`源代码/zhiguang_be/src/main/java/com/tongji/knowpost/id/SnowflakeIdGenerator.java`

**作用**：生成全局唯一的 64 位雪花 ID，用于知文主键。

**核心字段**：
```java
- EPOCH = 1704067200000L         // 自定义纪元：2024-01-01 00:00:00 UTC
- WORKER_ID_BITS = 5L            // 5 位工作节点 ID（支持 32 个节点）
- DATACENTER_ID_BITS = 5L        // 5 位数据中心 ID（支持 32 个数据中心）
- SEQUENCE_BITS = 12L            // 12 位序列号（每毫秒 4096 个 ID）
```

**核心方法**：
- `nextId()`：线程安全地生成下一个 ID
  - 41 位时间戳 + 5 位数据中心 + 5 位工作节点 + 12 位序列号
  - 处理时钟回拨问题（小幅度回拨等待，大幅度回拨拒绝）
  - 同一毫秒内通过序列号递增保证唯一性

**后续改动**：单节点部署使用默认构造器 `SnowflakeIdGenerator()` 即可，多节点时需传入不同的 workerId。

#### 5. 获取详情 (`getDetail`) — 含三级缓存
```java
@Transactional(readOnly = true)
public KnowPostDetailResponse getDetail(long id, Long currentUserIdNullable) {
    String pageKey = "knowpost:detail:" + id + ":v" + DETAIL_LAYOUT_VER;
    
    // L1: Caffeine 本地缓存
    KnowPostDetailResponse local = knowPostDetailCache.getIfPresent(pageKey);
    if (local != null) {
        recordHotKeyAndExtendTtl(id, pageKey);
        return enrichDetailResponse(local, currentUserIdNullable, true);
    }
    
    // L2: Redis 分布式缓存
    String cached = redis.opsForValue().get(pageKey);
    KnowPostDetailResponse resp = tryProcessCacheHit(cached, id, pageKey, currentUserIdNullable, "page");
    if (resp != null) return resp;
    
    // SingleFlight 防止缓存击穿
    Object lock = singleFlight.computeIfAbsent(pageKey, k -> new Object());
    synchronized (lock) {
        // 双重检查
        String again = redis.opsForValue().get(pageKey);
        resp = tryProcessCacheHit(again, id, pageKey, currentUserIdNullable, "page(after-flight)");
        if (resp != null) {
            singleFlight.remove(pageKey);
            return resp;
        }
        
        // 回源查询数据库
        KnowPostDetailRow row = mapper.findDetailById(id);
        
        // 权限校验
        boolean isPublic = "published".equals(row.getStatus()) && "public".equals(row.getVisible());
        boolean isOwner = currentUserIdNullable != null && row.getCreatorId().equals(currentUserIdNullable);
        if (!isPublic && !isOwner) {
            throw new BusinessException(ErrorCode.BAD_REQUEST, "无权限查看");
        }
        
        // 组装响应
        resp = new KnowPostDetailResponse(...);
        
        // 写入 Redis + L1 缓存
        knowPostDetailCache.put(pageKey, resp);
        
        singleFlight.remove(pageKey);
        return enrichDetailResponse(resp, currentUserIdNullable, false);
    }
}
```

**关键点**：
- **缓存布局版本**：`DETAIL_LAYOUT_VER` 用于后续 schema 变更时 invalidate 旧缓存
- **空值缓存**：不存在的内容写入 `"NULL"` 30 秒，防穿透
- **热度检测**：`recordHotKeyAndExtendTtl()` 根据访问频率动态延长 TTL
- **计数刷新**：`enrichDetailResponse()` 从 CounterService 拉取实时点赞/收藏数

```java
@Transactional
public ProfileResponse updateProfile(long userId, ProfilePatchRequest req) {
    User current = userMapper.findById(userId);
    if (current == null) {
        throw new BusinessException(ErrorCode.IDENTIFIER_NOT_FOUND, "用户不存在");
    }
    
    // 至少提交一个字段
    boolean hasAnyField = req.nickname() != null || req.bio() != null || ...;
    if (!hasAnyField) {
        throw new BusinessException(ErrorCode.BAD_REQUEST, "未提交任何更新字段");
    }
    
    // 知光号唯一性校验
    if (req.zgId() != null && !req.zgId().isBlank()) {
        boolean exists = userMapper.existsByZgIdExceptId(req.zgId(), current.getId());
        if (exists) {
            throw new BusinessException(ErrorCode.ZGID_EXISTS);
        }
    }
    
    // 构造 patch 对象（仅非空字段）
    User patch = getUser(req, current);
    userMapper.updateProfile(patch);
    
    // 回读最新快照
    User updated = userMapper.findById(userId);
    return toResponse(updated);
}
```

#### 2. 生成预签名 PUT URL
```java
public String generatePresignedPutUrl(String objectKey, String contentType, int expiresInSeconds) {
    ensureConfigured();
    
    Date expiration = new Date(System.currentTimeMillis() + expiresInSeconds * 1000L);
    GeneratePresignedUrlRequest request = new GeneratePresignedUrlRequest(
        props.getBucket(), objectKey, HttpMethod.PUT);
    request.setExpiration(expiration);
    request.setContentType(contentType);  // 客户端必须使用一致的 Content-Type
    
    URL url = client.generatePresignedUrl(request);
    return url.toString();
}
```

**设计要点**：
- 前端直传 OSS，不走后端流量
- 预签名 URL 有效期 10 分钟
- 上传完成后后端通过 `contentUrl` 字段存储公共访问地址

```typescript
uploadToPresigned: async (putUrl: string, headers: Record<string, string>, file: File) => {
    const resp = await fetch(putUrl, {
        method: "PUT",
        headers,
        body: file,
        credentials: "omit"
    });
    const etag = resp.headers.get("ETag") || "";
    return {etag};
}

// 计算文件 SHA-256
computeSha256: async (file: File) => {
    const buf = await file.arrayBuffer();
    const digest = await crypto.subtle.digest("SHA-256", buf);
    const hex = Array.from(new Uint8Array(digest)).map(b => b.toString(16).padStart(2, "0")).join("");
    return hex;
}
```

```typescript
const handlePublish = async () => {
    // 1. 创建草稿
    const id = await ensureDraft();
    
    // 2. 预签名上传正文（Markdown 文件）
    const file = new File([content], "content.md", {type: "text/markdown"});
    const size = file.size;
    const sha256 = await computeSha256(file);
    const presign = await knowpostService.presign({

    await knowpostService.update(id, {
        title: title.trim(),
        tags: tags.length ? tags : undefined,
        imgUrls: uploadedImgUrls.length ? uploadedImgUrls : undefined,
        visible: visiblePublic ? "public" : "private",
        isTop: false,
        description: description || undefined
    });
    
    // 5. 发布
    await knowpostService.publish(id);
};
```

## 四、常见问题

### Q1: 预签名 URL 上传失败？
**A**: 检查三点：
1. OSS 配置（endpoint/accessKeyId/accessKeySecret/bucket）是否正确
2. 前端上传时 `Content-Type` 是否与签名时一致
3. CORS 规则是否允许 PUT 方法

### Q2: 知文详情缓存不更新？
**A**: 检查 `invalidateCache()` 是否在事务前后都被调用（缓存双删）

### Q3: 知光号唯一性校验失败？
**A**: 确保 `existsByZgIdExceptId` 排除了当前用户 ID
