# 知光前端 — 从0到完整项目的8阶段开发路线图

> 本文档是前端开发的总体框架，每个阶段的具体教学在对应子文件中。

## 项目技术栈
React 18 + TypeScript + Vite 5 + React Router 6 + CSS Modules

## 参考完整版目录：`源代码/新修改/`

---

## 阶段总览

| 阶段 | 主题 | 核心产出 | 完成标志 |
|------|------|----------|----------|
| 一 | 项目骨架 | 配置、入口、路由、设计令牌 | `npm run dev` 能跑，路由不报错 |
| 二 | API 层 | OpenAPI 类型、统一请求客户端、业务类型 | 所有 API 调用走 client，页面不写 fetch |
| 三 | 认证系统 | AuthContext、登录/注册页、Token 管理 | 能注册、登录、保持会话、自动刷新 |
| 四 | 布局导航 | Sidebar + MainHeader + AppLayout + 图标 | 所有页面有统一侧边栏+头部 |
| 五 | 通用组件 | CourseCard、LikeFavBar、FollowButton、SearchBar、Tag等 | 可复用组件库就绪 |
| 六 | 核心业务页 | 首页Feed、搜索、创作、详情、个人主页、编辑资料 | 基本 CRUD + 浏览闭环 |
| 七 | AI 功能 | AI摘要生成、RAG问答（SSE流式） | 创作页能AI摘要，详情页能AI问答 |
| 八 | 关系互动 | 关注/取关、粉丝列表、计数器 | 社交互动闭环 |

## 阶段一：项目骨架与基础设施

### 1.1 初始化工程
| 文件 | 职责 |
|------|------|
| `package.json` | 依赖管理、脚本命令（dev/build/lint/openapi） |
| `vite.config.ts` | Vite 配置：React 插件、端口5173、代理 `/api`→`localhost:8080`、路径别名 `@`→`src` |
| `tsconfig.json` + `tsconfig.node.json` | TypeScript 编译选项：ESNext、strict、JSX react-jsx、路径别名 |
| `postcss.config.js` | PostCSS + autoprefixer |

### 1.2 入口文件
| 文件 | 职责 |
|------|------|
| `index.html` | HTML 壳子，加载 `src/main.tsx` |
| `src/main.tsx` | React 挂载：StrictMode → BrowserRouter → AuthProvider → App |

### 1.3 路由定义
| 文件 | 职责 |
|------|------|
| `src/App.tsx` | 9条路由 + 通配重定向，纯路由表不做业务逻辑 |

### 1.4 设计令牌与全局样式
| 文件 | 职责 |
|------|------|
| `src/theme/tokens.ts` | JS 设计令牌：暖橙色主色、圆角、阴影、布局尺寸 |
| `src/theme/index.ts` | 统一导出 |
| `src/index.css` | CSS 变量、全局重置、app-shell 网格布局、响应式断点 |

## 数据流全景

```
用户操作 → Page 组件 → Service 模块 → api/client.ts（自动带 Token）
                                              ↓
                                        fetch() → Vite 代理 → localhost:8080
                                              ↓
                                        Spring Boot 后端
                                              ↓
用户看到 ← Page 渲染 ← React State 更新 ← JSON 响应
```

## AI 数据流

```
AI 摘要：用户点击 → POST /description/suggest {content} → DeepSeek → 返回摘要 → 填入表单
RAG 问答：用户输入 → EventSource GET /qa/stream → ES向量检索 → DeepSeek流式 → SSE逐字 → 实时渲染
```
