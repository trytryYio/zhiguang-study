### 2.2 渐进式开发流程

#### 步骤 1：识别核心功能

**问题**：如何从复杂代码中识别核心功能？

**方法**：
1. 查看接口定义，找出必须实现的方法
2. 分析数据流，找出数据访问的核心路径
3. 查看数据库表结构，找出核心实体

**示例**：
```java
// KnowPostService 接口
public interface KnowPostService {
    long createDraft(long creatorId);           // ✅ 核心：创建草稿
    void confirmContent(...);                  // ✅ 核心：确认内容
    void updateMetadata(...);                  // ✅ 核心：更新元数据
    void publish(long creatorId, long id);     // ✅ 核心：发布
    void updateTop(...);                        // ⏸️ 可选：置顶
    void updateVisibility(...);                 // ⏸️ 可选：可见性
    void delete(long creatorId, long id);       // ⏸️ 可选：删除
```

**核心功能清单**：
- ✅ 创建草稿

**可选功能清单**：
- ⏸️ 置顶

#### 步骤 2：实现核心功能

**原则**：
1. 只实现核心功能，忽略所有高级特性
2. 使用简单的实现，不要过度设计
3. 添加必要的日志，便于调试

**示例**：
```java
// ✅ 简单实现：创建草稿
@Transactional
public long createDraft(long creatorId) {
    long id = idGen.nextId();
    Instant now = Instant.now();

    KnowPost post = KnowPost.builder()
        .id(id)
        .creatorId(creatorId)
        .status("draft")
        .type("image_text")
        .visible("public")
        .isTop(false)
        .createTime(now)
        .updateTime(now)
        .build();

    mapper.insertDraft(post);
    log.info("创建草稿成功，id={}, creatorId={}", id, creatorId);

    return id;
}

// ✅ 简单实现：获取详情
@Transactional(readOnly = true)
public KnowPostDetailResponse getDetail(long id, Long currentUserIdNullable) {
    log.info("获取帖子详情，id={}, currentUserId={}", id, currentUserIdNullable);

    // 1. 数据库查询
    KnowPostDetailRow row = mapper.findDetailById(id);
    if (row == null) {
        log.warn("帖子不存在，id={}", id);
        throw new BusinessException(ErrorCode.NOT_FOUND, "内容不存在");
    }

    // 2. 权限校验
    boolean isPublic = "published".equals(row.getStatus()) && "public".equals(row.getVisible());
    boolean isOwner = currentUserIdNullable != null && currentUserIdNullable.equals(row.getCreatorId());
    if (!isPublic && !isOwner) {
        log.warn("无权限查看，id={}, currentUserId={}", id, currentUserIdNullable);
        throw new BusinessException(ErrorCode.FORBIDDEN, "无权限查看");
    }

    // 3. 组装响应
    List<String> images = parseStringArray(row.getImgUrls());
    List<String> tags = parseStringArray(row.getTags());

    KnowPostDetailResponse response = new KnowPostDetailResponse(
        String.valueOf(row.getId()),
        row.getTitle(),
        row.getDescription(),
        row.getContentUrl(),
        images,
        tags,
        String.valueOf(row.getCreatorId()),
        row.getAuthorAvatar(),
        row.getAuthorNickname(),
        row.getAuthorTagJson(),
        0L,  // likeCount - 暂时返回 0
        0L,  // favoriteCount - 暂时返回 0
        false,  // liked - 暂时返回 false
        false,  // faved - 暂时返回 false
        row.getIsTop(),
        row.getVisible(),
        row.getType(),
        row.getPublishTime()
    );

    log.info("获取帖子详情成功，id={}", id);
    return response;
}
```

```java
       }
```

   ```java
   @Service
   public class SearchServiceImpl implements SearchService {
       private final ElasticsearchClient client;

       @Override
       public void indexPost(KnowPost post) {
           try {
               IndexRequest<KnowPost> request = IndexRequest.of(i -> i
                   .index("knowposts")
                   .id(String.valueOf(post.getId()))
                   .document(post)
               );
               client.index(request);
           } catch (Exception e) {
               log.error("索引帖子失败", e);
           }
       }

       @Override
       public void deletePost(long id) {
           try {
               DeleteRequest request = DeleteRequest.of(d -> d
                   .index("knowposts")
                   .id(String.valueOf(id))
               );
               client.delete(request);
           } catch (Exception e) {
               log.error("删除索引失败", e);
           }
       }

       @Override
       public List<KnowPost> search(String query, int page, int size) {
           try {
               SearchRequest request = SearchRequest.of(s -> s
                   .index("knowposts")
                   .from((page - 1) * size)
                   .size(size)
                   .query(q -> q
                       .multiMatch(m -> m
                           .query(query)
                           .fields("title^2", "description", "content")
                       )
                   )
               );

               SearchResponse<KnowPost> response = client.search(request, KnowPost.class);
               return response.hits().hits().stream()
                   .map(hit -> hit.source())
                   .collect(Collectors.toList());
           } catch (Exception e) {
               log.error("搜索失败", e);
               return Collections.emptyList();
           }
       }

       @Override
       public List<String> suggest(String prefix) {
           try {
               SearchRequest request = SearchRequest.of(s -> s
                   .index("knowposts")
                   .size(10)
                   .suggest(suggest -> suggest
                       .suggesters("title_suggest", suggester -> suggester
                           .prefix(prefix)
                           .completion(c -> c.field("title.suggest"))
                       )
                   )
               );

               SearchResponse<KnowPost> response = client.search(request, KnowPost.class);
               return response.suggest().get("title_suggest").get(0).options().stream()
                   .map(option -> option.text())
                   .collect(Collectors.toList());
           } catch (Exception e) {
               log.error("联想建议失败", e);
               return Collections.emptyList();
           }
       }
   }
   ```

## 九、总结

### 9.1 核心要点

1. **先跑起来，再优化**
   - 优先实现核心功能
   - 暂时忽略高级特性
   - 逐步添加优化

2. **接口先行，实现渐进**
   - 先定义接口
   - 实现核心方法
   - 逐步完善其他方法

3. **依赖解耦，Mock 优先**
   - 只依赖核心服务
   - 可选依赖用 @Nullable
   - 使用 try-catch 处理异常

4. **每次只添加一个特性**
   - 添加特性后立即测试
   - 保持代码简洁
   - 避免过度设计

### 9.2 渐进式开发流程

```
阶段 0：核心功能修复 (1-2天)
  ├─ 修复 KnowPostServiceImpl.getDetail()
  ├─ 修复 KnowPostFeedServiceImpl.getPublicFeed()
  └─ 补全 CaffeineConfig

阶段 1：基础功能完善 (2-3天)
  ├─ 实现完整的 CRUD 操作
  ├─ 添加权限校验
  ├─ 添加状态管理
  ├─ 实现基础缓存（L1 + L2）
  └─ 实现基础计数（数据库字段）

阶段 2：高级特性 (3-5天)
  ├─ 实现完整三级缓存
  ├─ 实现完整计数系统
  ├─ 实现搜索功能
  └─ 实现 AI 功能

阶段 3：优化完善 (2-3天)
  ├─ 数据库索引优化
  ├─ 查询优化
  ├─ 缓存策略优化
  ├─ 监控和日志
  └─ 测试覆盖
```

### 9.3 关键技巧

1. **如何识别核心功能**
   - 查看接口定义
   - 分析数据流
   - 查看数据库表结构

2. **如何暂时注释依赖**
   - 使用 @Nullable
   - 使用 try-catch
   - 使用默认值

3. **如何逐步添加特性**
   - 每次只添加一个特性
   - 添加特性后立即测试
   - 保持代码简洁

4. **如何调试复杂代码**
   - 添加日志
   - 使用断点调试
   - 使用单元测试
