# 知光平台 - 前端开发阶段规划

与后端 6 个阶段一一对应，前端也分为 6 个阶段。每个阶段的前端工作都在对应后端阶段完成后进行对接。

---

## 第一阶段：项目脚手架搭建（对应后端：基础环境搭建）

### 1. 项目初始化
- 使用 Vite + React + TypeScript 创建项目
- `npm create vite@latest zhiguang_fe -- --template react-ts`
- 配置 `package.json` 依赖：react-router-dom
- 创建 `index.html`（标题 "知光 - 让知识发光"）
- 配置 `postcss.config.js`（autoprefixer）

### 2. 基础工程结构
- 创建目录骨架：`src/`, `src/components/`, `src/pages/`, `src/services/`, `src/types/`, `src/context/`, `src/theme/`
- 创建 `vite.config.ts`，配置 `server.proxy` 代理 `/api` 到后端 `http://localhost:8080`
- 创建 `.env.development`，配置 `VITE_API_BASE_URL`

### 3. 全局样式与主题
- `src/index.css` — CSS 变量定义（主色 `#ff8a41`、成功/信息色、圆角、阴影、布局变量）
- `src/theme/tokens.ts` — 导出 colors / radii / shadows / layout 对象
- `src/theme/index.ts` — 统一 re-export

### 4. 路由基础
- `src/App.tsx` — 定义基础路由（`/`, `/login`, `/register`）
- `src/main.tsx` — 入口，挂载 BrowserRouter + React.StrictMode

> **阶段一前端不依赖后端 API**，可以独立完成。完成后应能看到带主题色、侧边栏、路由切换的空壳应用。

## 第二阶段：认证系统对接（对应后端：用户认证系统）

### 5. 类型定义
- `src/types/auth.ts` — 定义所有认证相关 TS 类型：
  - LoginRequest / RegisterRequest / AuthResponse / TokenResponse
  - AuthUserResponse / LoginResponse / LogoutRequest / RefreshResponse
  - IdentifierType / VerificationScene 等枚举
  - AuthenticatedUser（前端本地使用的用户类型）

### 6. API 服务层
- `src/services/apiClient.ts` — 通用 fetch 封装：
  - 自动拼接 `VITE_API_BASE_URL`
  - 自动附加 `Authorization: Bearer <token>`
  - 处理 401/403 跳转登录
  - 支持 FormData（跳过 JSON Content-Type）
- `src/services/authService.ts` — 认证相关 API 封装：
  - `sendCode()` → POST `/api/v1/auth/send-code`
  - `register()` → POST `/api/v1/auth/register`
  - `login()` → POST `/api/v1/auth/login`
  - `logout()` → POST `/api/v1/auth/logout`
  - `fetchCurrentUser()` → GET `/api/v1/auth/me`
  - `refreshToken()` → POST `/api/v1/auth/token/refresh`

### 7. 认证状态管理
- `src/context/AuthContext.tsx` — React Context 全局状态：
  - `user`, `tokens`, `isLoading` 状态
  - `login()`, `register()`, `logout()`, `refresh()` 操作
  - localStorage 持久化（`zhiguang_auth_tokens`, `zhiguang_current_user`）
  - 自动刷新定时器（60 秒检查一次，接近过期时刷新）
  - 导出 `useAuth()` hook

### 8. 登录/注册页面
- `src/pages/LoginPage.tsx` — 手机号 + 验证码登录表单
  - 调用 `authService.sendCode()` 发送验证码
  - 60 秒倒计时
  - 调用 `authService.login()` 登录
  - 成功后通过 `location.state.from` 跳回来源页
- `src/pages/RegisterPage.tsx` — 手机号 + 验证码 + 密码注册
  - 60 秒倒计时
  - 用户协议勾选
  - 注册成功后自动登录并跳转

### 9. 认证状态展示组件
- `src/features/auth/AuthStatus.tsx` — 头部登录状态：
  - 未登录：显示 "登录" 按钮（ghost-button），点击跳转 `/login` 并保存来源路径
  - 已登录：显示 `UserBadge`（头像 + 昵称） + "退出" 按钮
- `src/components/common/UserBadge.tsx` — 用户信息小卡片：头像 + 昵称

> **阶段二完成后**：用户可以注册、登录、看到登录状态、退出登录。

## 第三阶段：个人资料与内容发布（对应后端：核心业务功能）

### 10. 类型定义扩展
- `src/types/profile.ts` — ProfileResponse / ProfileUpdateRequest / Gender 枚举
- `src/types/knowpost.ts` — 知文核心类型：
  - FeedItem / FeedResponse（列表项 + 分页）
  - KnowpostDetailResponse（详情页数据）
  - CreateDraftResponse / PresignRequest / PresignResponse / ConfirmContentRequest
  - UpdateKnowPostRequest / VisibleScope 枚举
  - LikeActionResponse / FavActionResponse / CounterResponse
- `src/types/content.ts` — 内容辅助类型（ContentTag / Mentor 等）

### 11. 个人资料服务与页面
- `src/services/profileService.ts`：
  - `updateProfile()` → PATCH `/api/v1/profile`
  - `uploadAvatar()` → POST `/api/v1/profile/avatar`（FormData）
- `src/pages/ProfilePage.tsx` — 个人主页：
  - 展示头像、昵称、bio、标签
  - RelationCounters 组件（关注/粉丝/知文数等）
  - "我的知文" 列表（调用 `knowpostService.mine()`）
  - 支持置顶/可见性切换/删除（editable 模式）
- `src/pages/EditProfilePage.tsx` — 编辑个人资料：
  - 头像上传（调用 profileService.uploadAvatar）
  - 昵称 / 手机号 / zgId / 性别 / 生日 / 学校 / 技能标签 / 简介
  - 保存后调用 `reloadUser()` 同步全局状态

### 12. 内容发布系统
- `src/services/knowpostService.ts` — 知文 API 封装：
  - `createDraft()` → POST `/api/v1/knowposts/drafts`
  - `presign()` → POST `/api/v1/storage/presign`（获取预签名上传 URL）
  - `confirmContent()` → POST `/api/v1/knowposts/:id/content/confirm`
  - `updatePost()` → PATCH `/api/v1/knowposts/:id`
  - `publishPost()` → POST `/api/v1/knowposts/:id/publish`
  - `toggleTop()` / `updateVisibility()` / `deletePost()`
  - `feed()` / `mine()` / `detail()` — 查询接口
  - `suggestDescription()` — AI 摘要生成
  - `uploadToPresigned()` — 直传 OSS 辅助函数
  - `computeSha256()` — 文件哈希计算辅助函数
- `src/pages/CreatePage.tsx` — 发布知文表单：
  - 标题、正文（textarea）、标签（TagInput）、摘要、可见性
  - 图片上传（最多 15 张，走 presign → upload 流程）
  - AI 生成摘要按钮
  - 发布流程：创建草稿 → 预签名上传 Markdown → 确认内容 → 更新元数据 → 发布

### 13. 布局与通用组件
- `src/components/layout/AppLayout.tsx` — 主布局（侧边栏 + 内容区）
- `src/components/layout/MainHeader.tsx` — 页面头部（标题 + 副标题 + tabs + rightSlot）
- `src/components/layout/Sidebar.tsx` — 侧边栏导航（首页/搜索/创建/学习/我的）
- `src/components/common/Tag.tsx` — 标签组件（primary / success / neutral 三种色调）
- `src/components/common/TagInput.tsx` — 多标签输入（Enter 添加，Backspace 删除）
- `src/components/common/SectionHeader.tsx` — 区块标题 + 右侧操作按钮
- `src/components/icons/Icon.tsx` — SVG 图标工厂（Home/Search/Create/Study/Profile/Spark/Heart/Bookmark 等）

> **阶段三完成后**：用户可以编辑个人资料、发布知文（含图片上传）、查看个人主页和我的知文列表。

## 第四阶段：社交互动（对应后端：社交与互动）

### 14. 类型定义
- `src/types/relation.ts` — RelationStatusResponse / RelationCountersResponse
- `src/types/search.ts` — SearchResponse（cursor 分页）/ SuggestResponse

### 15. 社交关系服务与组件
- `src/services/relationService.ts`：
  - `follow()` / `unfollow()` → POST `/api/v1/relation/follow|unfollow`
  - `getStatus()` → GET `/api/v1/relation/status`
  - `getFollowing()` / `getFollowers()` → cursor 分页列表
  - `counters()` → GET `/api/v1/relation/counter`
- `src/components/common/FollowButton.tsx` — 关注/取关按钮：
  - 挂载时获取关系状态
  - 切换关注状态，显示 "互关" 标记
  - 未登录时隐藏
- `src/components/common/RelationCounters.tsx` — 计数展示（关注/粉丝/知文/点赞/收藏）
  - "关注" 和 "粉丝" 可点击打开弹窗
- `src/components/common/RelationListModal.tsx` — 关注/粉丝列表弹窗
  - cursor 分页，"加载更多" 按钮

### 16. 点赞/收藏组件
- `src/components/common/LikeFavBar.tsx` — 点赞收藏栏：
  - 心形 + 书签图标
  - 支持初始计数/状态传入
  - 可选 `fetchCounts` 挂载时拉取计数
  - 乐观更新（点击立即切换 UI）
  - 未登录跳转登录页
- 集成 `knowpostService.like/unlike/fav/unfav` 调用
- 集成 `knowpostService.getCounters` 调用

### 17. 首页 Feed 流
- `src/pages/HomePage.tsx` — 首页：
  - 调用 `knowpostService.feed(page, size)` 拉取公开 Feed
  - 瀑布流卡片布局（CourseCard）
  - 每张卡片带 LikeFavBar 底部栏
- `src/components/cards/CourseCard.tsx` — 知文卡片：
  - 封面图 + 标题 + 描述 + 标签
  - 作者头像 + 昵称 + 标签
  - `footerExtra` 插槽（放入 LikeFavBar）
  - `editable` 模式：支持置顶/可见性/删除操作（Profile 页复用）

> **阶段四完成后**：用户可以关注/取关他人、查看关注/粉丝列表、点赞/收藏知文、浏览首页 Feed 流。

## 第五阶段：搜索与 AI 功能（对应后端：消息队列 + AI 集成）

### 18. 搜索服务与页面
- `src/services/searchService.ts`：
  - `query()` → GET `/api/v1/search?q=&size=&tags=&after=`（cursor 分页）
  - `suggest()` → GET `/api/v1/search/suggest?prefix=&size=`（前缀联想）
- `src/pages/SearchPage.tsx` — 搜索页：
  - SearchBar 组件，提交后调用 `searchService.query()`
  - 300ms 防抖调用 `searchService.suggest()` 显示联想结果
  - 支持 "加载更多"（cursor 分页）
  - 未登录用户显示登录提示
- `src/components/common/SearchBar.tsx` — 搜索输入框：
  - 搜索图标 + 提交按钮
  - 联想结果下拉框
  - "加载中" / "无联想结果" 状态

### 19. AI 问答集成
- 在 `CourseDetailPage.tsx` 中集成 RAG 问答：
  - 使用 `EventSource` 连接 `/api/v1/knowposts/:id/qa/stream`
  - 流式渲染 AI 回答（SSE 事件流）
  - 侧边栏 Q&A 面板
- `@coze/api` 集成（如需要第三方 AI 对话）

### 20. Markdown 渲染
- 安装 `react-markdown` + `remark-gfm`
- `CourseDetailPage.tsx` 中渲染知文正文（从 contentUrl 获取 Markdown 文本）
- 图片画廊：响应式图片行 + 溢出徽标（+N）+ 全屏查看 + 上一张/下一张导航

> **阶段五完成后**：用户可以搜索知文、获得搜索联想、在知文详情页进行 AI 问答。

- Token 自动刷新逻辑优化（减少不必要的服务端请求）
- CSS 响应式断点完善（1200px / 1024px / 900px / 700px / 540px）

> **阶段六完成后**：前端体验完善，响应式适配，性能优化到位。

## 前后端阶段对照表

| 阶段 | 后端工作 | 前端工作 | 前端依赖后端 |
|------|---------|---------|------------|
| 一 | Spring Boot 初始化、数据库、Redis | Vite 项目、路由、主题、样式 | 否（纯前端） |
| 二 | JWT、登录注册、验证码 | AuthContext、登录/注册页、apiClient | 是（需认证 API） |
| 三 | 用户资料、知文 CRUD、OSS | 个人资料页、发布页、布局组件 | 是（需资料 + 内容 API） |
| 四 | 关注关系、计数系统 | 关注按钮、点赞收藏、首页 Feed | 是（需关系 + 计数 API） |
| 五 | Kafka、Canal、AI 集成 | 搜索页、AI 问答、Markdown 渲染 | 是（需搜索 + RAG API） |
| 六 | 缓存策略、Feed 流优化 | 学习页、性能优化、响应式 | 部分（缓存对前端透明） |
