## 关键设计模式速查

| 模式 | 应用模块 | 说明 |
|------|---------|------|
| Outbox 模式 | relation, counter | 同一事务写业务表 + Outbox 表，Canal → Kafka 异步传播 |
| 三级缓存 | knowpost (Feed) | L1 Caffeine → L2 Redis → L3 DB |
| 位图计数 | counter | 分片 Redis 位图 + Lua 脚本原子操作 |
| 事件驱动 | relation, counter | Outbox → Canal → Kafka → Consumer |
| 单飞锁 | knowpost (Feed) | 防止同一页并发回源风暴 |
| 热点探测 | cache, knowpost | 滑动窗口统计，动态延长 TTL |
| RAG | llm | 向量检索 → Prompt 构造 → LLM 流式生成 |
| 渐进式发布 | knowpost, storage | OSS 预签名 + 前端直传 |

## 学习建议

1. **先理解再动手**：每个模块先看参考实现，理解后再写
2. **按依赖顺序**：Entity → Mapper → Service → Controller
3. **小步提交**：每完成一个模块就测试一次，用git commit记录
4. **参考AGENTS.md**：里面有详细的架构说明和坑点
5. **遇到编译错误**：先看错误信息，找到对应的参考文件对比
6. **不要追求完美**：P2可选功能可以后续再补
