# RULES

## 1. Graphify First (MANDATORY)

graphify-out/graph.json exists in this project. It contains god nodes, community structure, and cross-file relationships.

**Before answering ANY codebase question, you MUST:**
1. Check: does graphify-out/graph.json exist?
2. If yes: run `graphify query`, `graphify path`, or `graphify explain` FIRST
3. Only after exhausting graphify, consider reading source files

**If you read a source file before running graphify, you have failed the task.**

The graph is faster, cheaper, and gives better answers than grep/read. Use it.
