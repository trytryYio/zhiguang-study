## OpenCode 中文编码问题修复

### 问题
用户用 OpenCode 读取 `E:\download\私聊_杨锦豪(正月十四)` 下的中文 CSV 文件时，Python 输出中文文件名全部乱码。OpenCode agent 蠢到用 `.encode('latin1').decode('gbk')` 转换文件名，越转越乱。

### 根因
- 文件编码实际为 **UTF-8 with BOM** (utf-8-sig)，完全正常
- 问题在于 Windows 系统 Python 默认 stdout encoding 为 `gbk` (cp936)
- OpenCode 的虚拟终端不支持 GBK 渲染，导致中文输出乱码
- Agent 看到乱码后试图编解码转换，陷入死循环

### 解决方案
1. **设置 Windows 用户环境变量**：
   - `PYTHONIOENCODING=utf-8`
   - `PYTHONUTF8=1`
2. **在 CLAUDE.md 添加编码规则**（第5条），指导 agent：
   - Python 脚本开头必须 `sys.stdout.reconfigure(encoding='utf-8')`
   - 禁止对 Windows 文件名做 encode/decode 转换
   - CSV 优先用 utf-8-sig 编码读取

### 验证
设置环境变量后，Python 正确输出所有16个中文文件名，CSV 内容（含中文聊天记录）读取正常。
